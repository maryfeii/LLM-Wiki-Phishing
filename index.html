Scope & honesty

這個 Wiki 如何運作？

本作品為可離線執行的「來源導向知識庫」原型：先人工確認官方資料，再將重點整理為結構化條目，透過瀏覽器內建搜尋進行檢索。簡報內容依條目設計並標註來源 ID。這不是已連線到外部 LLM API 的自動問答系統；若課堂要求特定 LLM Wiki 平台的真實 ingest，需要另外把這六篇資料匯入該平台。
